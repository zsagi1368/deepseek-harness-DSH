## 2. 依赖图（调度用）

```
G0: T0.1 ∥ T0.2 ∥ T0.5 → T0.3 → T0.4
G1: T1.1 → T1.2 → T1.3 → T1.4 → T1.5        （T3.2 可在 T1.4 后提前做）
G2: T2.1 → T2.2 → {T2.3, T2.4} ; T2.3 → T2.5 → T2.6
    T2.7 ∥ (T2.1..T2.6) ; T2.7 → T2.8 ; T2.4 → T2.9
G3: T3.1 (依赖 T2.2) ; T3.3 (依赖 T2.2) ; T3.4 (依赖 T2.7)
G4: T4.1 (依赖 G2) → T4.2 ; T4.3 (依赖 T2.6) → T4.4
G5: T5.1 → T5.2 → T5.3 → {T5.4, T5.5}
```

并行度建议：同一时刻最多 3 个执行代理并行（P2 期间典型编队：DEV-PLUGIN + DEV-CORE + QA）；**同一包目录同时只允许一个代理改动**（包级互斥：packages/plugins/**、packages/client/ui-plugin-manager/**、credentials 区等）。
