## 二、设计方案

### P0-1: contextWindow 动态读取 + 配置化

**设计原则**:
1. 优先从 LLM 适配器 model catalog 读取实际值
2. 读取失败时退回到各 adapter 的 DEFAULT_CONTEXT_WINDOW
3. 用户可在 cordis.yml 中覆盖
4. agent-loop 通过 injection 获取值，不再硬编码

**实现步骤**:
```
1. packages/llm/llm/src/types.ts: 新增 LlmModelInfo.contextWindow
2. packages/core/session/src/index.ts: deriveMessages() 签名不变
3. packages/core/agent-loop/src/agent.ts: inject 'llm' 获取当前 model contextWindow
4. packages/settings/settings/src/context-window.ts: 新增 Settings 键
```

**UI 暴露**:
- 在 settings panel 显示 "Context Window" (只读 + 可覆盖)
- 显示格式: "256K tokens (DeepSeek v4 Flash)"
