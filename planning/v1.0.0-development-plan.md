## 技术决策

### 1. 滑动上下文窗口设计

**方案**: 在 `deriveMessages()` 增加 `contextWindow` 参数，只返回最近 N 轮完整内容。

```typescript
// packages/core/session/src/index.ts
deriveMessages(options?: {
  contextWindow?: number  // tokens
  minTurns?: number       // 至少保留多少完整 turn
  summaryThreshold?: number  // 超过此 token 数触发早期 turn 摘要
}): Message[]
```

**权衡**: 
- ✅ 直接控制 prompt 大小
- ⚠️ 可能丢失早期任务的精确细节（可通过 embedding 检索补偿）

### 2. 工具结果大小限制

**方案**: `ToolDefinition` 新增可选 `maxResultBytes` 字段。

```typescript
interface ToolDefinition extends ToolSchema {
  output: ToolOutputDefinition
  execute(args: unknown, exec: ToolRunContext): Promise<unknown>
  maxResultBytes?: number  // 可选，超出则截断+标记
}
```

**权衡**:
- ✅ 开发者可精确控制单工具输出
- ⚠️ 需要向后兼容（可选字段）

### 3. 凭证加密

**方案**: AES-256-GCM 透明加密，key 由用户密码派生（PBKDF2）。

```typescript
// packages/credentials/credentials/src/encrypted-provider.ts
class EncryptedCredentialProvider extends CredentialProvider {
  private deriveKey(password: string): Promise<CryptoKey>
  private encrypt(value: string, key: CryptoKey): Promise<string>
  private decrypt(ciphertext: string, key: CryptoKey): Promise<string>
}
```

**权衡**:
- ✅ 零信任架构，密钥不进内存明文
- ⚠️ 密码丢失 = 永久无法解密
